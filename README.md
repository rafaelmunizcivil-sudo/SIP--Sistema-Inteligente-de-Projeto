# SIP - Sistema Inteligente de Projetos

## Visão Geral

O SIP (Sistema Inteligente de Projetos) é uma plataforma para gestão integrada de projetos de infraestrutura.

## Objetivos

- Gestão de Clientes
- Gestão de Contratos
- Gestão de Projetos
- Gestão de Disciplinas
- Gestão de RAPs
- Dashboard Executivo
- Indicadores de Desempenho
- Inteligência Artificial

## Tecnologias

- React
- Firebase
- Power BI
- GitHub
- Claude Design
